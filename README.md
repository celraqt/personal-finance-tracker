# Personal Finance Tracker (PFT)

A Web-Based Income and Expense Management System

## Project Description

Personal Finance Tracker (PFT) is a responsive web application
that helps users manage income, expenses, budgets, savings goals,
and financial reports.

Developed as a final project for Web Systems Technology.

## Features

- User Registration, Login, and Logout
- User Dashboard with Financial Summaries
- Income and Expense Transaction Management
- Custom Income and Expense Categories
- Monthly Budget Management and Spending Alerts
- Savings Goals and Contribution Tracking
- Financial Charts and CSV Report Export
- Administrator Dashboard
- Account Suspension and Reactivation
- Account Appeals Management
- Responsive Web Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- PHP
- MySQL / MariaDB
- Fetch API
- Chart.js
- Git and GitHub

## Local Installation

1. Install XAMPP.
2. Copy the project folder into `C:\xampp\htdocs`.
3. Start Apache and MySQL.
4. Create the required database using phpMyAdmin.
5. Import the database schema.
6. Configure `config/database.php` with local database credentials.
7. Open the website in your browser.
